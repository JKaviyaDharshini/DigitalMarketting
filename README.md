# 🚀 FlyDigital Marketing Website

A modern, high-performance Digital Marketing Agency website built with React.js and Vite. The website features premium UI, smooth animations, responsive layouts, and SEO-friendly architecture.

---

## ✨ Features

- Modern & Premium UI
- Responsive Design
- Smooth Scrolling (Lenis)
- Beautiful Animations (Framer Motion)
- Fast Routing (React Router DOM)
- Animated Counters
- Service Pages
- Industry Pages
- Blog Section
- Contact Page
- Admin Dashboard (Basic)
- SEO Friendly Structure
- Optimized Performance

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/flydigital-marketing.git
```

Go to project

```bash
cd flydigital-marketing
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Create production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
